# V2V

Vehicle-to-Vehicle communication and intelligent road-safety platform.

## Overview

V2V is a web application focused on improving road safety through vehicle-to-vehicle communication. It is built with Next.js, Firebase, and Genkit to support a modern, responsive interface and AI-powered functionality.

## Tech Stack

- Next.js 15
- React 18
- TypeScript
- Firebase
- Google Genkit
- Tailwind CSS
- Recharts
- Radix UI

## Getting Started

### Prerequisites

- Node.js 20+
- npm
- A Firebase project configured for the application

### Installation

```bash
npm install
```

### Environment Variables

Create a `.env.local` file and add the credentials required by the Firebase and Genkit integrations used by the application.

### Run Locally

```bash
npm run dev
```

The development server runs on port `9002`.

## Available Scripts

```bash
npm run dev
npm run build
npm run start
npm run typecheck
npm run genkit:dev
npm run genkit:watch
```

## Project Structure

```text
src/       Application source code
public/    Static assets
docs/      Project documentation
```

## Purpose

The project explores how connected-vehicle communication and intelligent software can be used to deliver timely road-safety information and improve driver awareness.
